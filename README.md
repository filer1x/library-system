# 📚 Library System

Десктопна система керування бібліотекою, розроблена як курсова робота. Проєкт реалізований мовою **C** з використанням графічної бібліотеки **raylib** та системи автоматизації збірки **CMake**. Застосунок орієнтований на автоматизацію обліку книг та спрощення взаємодії між користувачами і бібліотечним фондом.

## ✨ Можливості

* **Авторизація та реєстрація:** безпечний вхід у систему для розподілу прав доступу.
* **Рольова модель:** чіткий розподіл функціоналу між звичайним користувачем та адміністратором.
* **Управління фондом:** додавання нових книг до бази даних (доступно адміністратору).
* **Навігація та пошук:** перегляд повного каталогу книг та швидкий пошук за назвою.
* **Взаємодія з книгами:** бронювання доступних примірників та можливість їхнього повернення.
* **Локалізація:** повна підтримка українського інтерфейсу.
* **Коректний шрифт:** інтеграція шрифту *DejaVuSans* для правильного рендерингу кирилиці в графічному вікні raylib.

## 🛠 Технології

* **Мова програмування:** C (стандарт C11 / C99)
* **Графічний інтерфейс (GUI):** raylib
* **Система збірки:** CMake
* **Збереження даних:** Бінарні файли (`.bin`)

---

## 📂 Структура проєкту

* `main.c` — ініціалізація графічного вікна, керування станами застосунку та основна логіка GUI.
* `library_core.c` — реалізація бізнес-логіки: робота з масивами книг/користувачів, валідація, файлове введення-виведення.
* `library_core.h` — оголошення ключових структур даних (`Book`, `User`) та прототипів функцій.
* `localization.h` — масиви рядків та константи для забезпечення української локалізації інтерфейсу.
* `CMakeLists.txt` — конфігураційний файл для збірки проєкту через CMake.
* `build.bat` / `run.bat` — командні скрипти для швидкої збірки та запуску в ОС Windows.
* `assets/DejaVuSans.ttf` — TrueType шрифт, що використовується для коректного відображення українських літер.
* `data.bin` — файл для персистентного збереження інформації про книги.
* `users.bin` — файл для збереження облікових записів користувачів.

## 🚀 Встановлення та запуск

### Варіант 1. Запуск готового релізу (Рекомендовано)

1. Перейдіть у розділ [Releases](https://github.com/filer1x/library-system/releases).
2. Завантажте архів із останнім стабільним випуском.
3. Розархівуйте вміст у зручну папку та запустіть виконавчий файл `LibraryApp.exe`.

> **Примітка:** якщо програма запускається з релізу, усі необхідні файли та залежності вже включені в один інсталяційний пакет.

### Варіант 2. Збірка з вихідного коду

Для компіляції проєкту вам знадобляться встановлений компілятор (наприклад, GCC або MSVC), CMake та налаштована бібліотека raylib. Виконайте наступні команди в терміналі з кореневої папки проєкту:

```bash
cmake -S . -B build
cmake --build build
.\build\Debug\LibraryApp.exe
```
Важливі примітки для розробників:

Для коректної локальної збірки у вашій системі або середовищі розробки має бути присутня папка (або встановлена бібліотека) raylib.

Для відображення українського тексту застосунок обов'язково потребує наявності файлу assets/DejaVuSans.ttf за відносним шляхом від місця запуску.
