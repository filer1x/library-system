FONT SETUP INSTRUCTIONS
========================

The updated Library App requires a TrueType font file named "font.ttf" in the same directory as the executable.

REQUIREMENTS:
- File name: font.ttf
- Must support Cyrillic characters (Ukrainian alphabet)
- Recommended size: Any TTF font works

RECOMMENDED FREE FONTS WITH CYRILLIC SUPPORT:
1. Roboto (Google Fonts)
2. Open Sans (Google Fonts)
3. DejaVu Sans
4. Liberation Sans
5. Noto Sans

WHERE TO DOWNLOAD:
- Google Fonts: https://fonts.google.com/
- Search for fonts with "Cyrillic" in the language support

INSTALLATION:
1. Download a TTF font file that supports Cyrillic
2. Rename it to "font.ttf"
3. Place it in: e:\Bodya\
4. Run the application

If the font fails to load, the app will fall back to Raylib's default font (but Cyrillic text won't render correctly).
